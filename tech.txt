ROM-Rot v2.5: Архитектура движка и технические спецификации
=========================================================

Этот документ содержит описание архитектуры плагина, ключевых DSP-алгоритмов и технических решений, реализованных в ROM-Rot (включая как версию синтезатора ROM-Rot, так и версию эффекта ROM-Rot FX).

1. ОБЩАЯ АРХИТЕКТУРА И ДВОЙНОЙ ТАРГЕТ (SYNTH & FX)
-------------------------------------------------
Плагин разработан на C++20 с использованием фреймворка JUCE 7.0.12. В CMakeLists.txt настроены два отдельных целевых плагина, разделяющих общую кодовую базу:
*   ROM-Rot (Synth): JUCE target `LofiChiptuneSynth` с `IS_SYNTH TRUE`. Работает как полноценный полифонический инструмент с MIDI-входом.
*   ROM-Rot FX (Effect): JUCE target `LofiChiptuneSynthFX` с `IS_SYNTH FALSE`. Работает как аудиоэффект на канале микшера, обрабатывая входящий стереосигнал.

Потокобезопасность (Thread Safety):
Связь между UI-потоком и аудиопотоком реального времени (Real-Time Audio Thread) реализована без блокировок (lock-free):
*   Параметры автоматизации и слайдеры привязаны к `juce::AudioProcessorValueTreeState` (APVTS).
*   Внутри `processBlock()` указатели на параметры кешируются как `std::atomic<float>*` для считывания значений с помощью relaxed-упорядочивания памяти (`std::memory_order_relaxed`).
*   Для переключения вкладок UI используется класс `WindowStateManager` с атомарными переменными и упорядочиванием `release` / `acquire` для синхронизации без мьютексов.

2. ДВИЖОК СИНТЕЗА (SYNTH ENGINE)
--------------------------------
Реализован в классах `SynthVoice` и `LofiChiptuneSynthAudioProcessor`.

*   Полифония и Voice Allocator: Поддерживается 8 независимых голосов `SynthVoice`. Распределение нот выполняется циклически. При нехватке голосов активируется алгоритм "голосов-заменителей" (voice stealing), который плавно выключает самый старый активный голос для предотвращения щелчков в звуке.
*   Осциллятор (Oscillator):
    *   Генерирует 4 формы волны: Sine (Синус), Triangle (Треугольник), Sawtooth (Пила) и Pulse (Импульс).
    *   Pulse-волна поддерживает модуляцию ширины импульса (PWM) с помощью встроенного LFO. Параметры `pwm_rate` и `pwm_depth` определяют скорость и глубину модуляции скважности.
    *   Sub-Osc: дополнительный суб-осциллятор генерирует синусоидальную волну на октаву ниже основной частоты с регулируемой громкостью (`sub_gain`) для добавления плотности низким частотам.
    *   Noise Generator: генератор псевдослучайного белого шума (`noise_gain`) для имитации перкуссионных ретро-звуков (например, шума взрывов в NES).
*   Унисон и Детюнинг (Detune): Расстройка высоты тона между голосами в диапазоне [-2.0, 2.0] полутонов для создания эффекта Stereo Widening.
*   Огибающая ADSR: Классическая огибающая `juce::ADSR` управляет амплитудой каждого голоса с нелинейным затуханием для классического аналогового ощущения.

3. ЛОУ-ФАЙ ПРОЦЕССОР (DSP LOFIENGINE / "ROT")
--------------------------------------------
Реализован в классе `LofiEngine`. Выполняет последовательную нелинейную и временную деградацию сигнала:

А. Wow & Flutter (Эмуляция детонации магнитофона)
Для модуляции высоты тона используется стереофонический кольцевой буфер задержки (`delayBuffer[2]`) объемом 4096 сэмплов (около 90 мс задержки).
*   Wow: Медленный плывущий тон, моделирующий биение вала магнитофона. Реализован с помощью LFO на частоте `wowSpeed` (~1.0–2.2 Гц).
*   Flutter: Быстрое дрожание звука, симулирующее шероховатости ленты. Частота LFO `flutterSpeed` (~8.0–14.0 Гц) модулируется дополнительным случайным микро-шумом для устранения искусственной периодичности.
*   Линейная интерполяция: Для чтения из буфера задержки по дробным индексам используется линейная интерполяция соседних сэмплов:
    `output = sample[floor] * (1 - frac) + sample[floor + 1] * frac`
    Это предотвращает цифровой треск при постоянном изменении времени задержки.
*   Эффект "Melt" (Замятие ленты): Случайный алгоритм генерирует кратковременные глубокие проседания скорости воспроизведения (задержка резко возрастает до 35 сэмплов), имитируя физическое замятие пленки.

Б. High-Shelf Filter (Частотный завал)
Однополюсный сглаживающий фильтр (Low-Pass 1-го порядка) имитирует спад высоких частот на магнитной головке:
`output[n] = state + alpha * (input[n] - state)`
Коэффициент `alpha` (`highShelfGain`) динамически меняется от 1.0 (полный обход) до 0.3 (глубокий срез ВЧ) в зависимости от положения макро-ручки Vibe.

В. Tape Saturation (Насыщение)
Нелинейный дисторшн реализован через функцию гиперболического тангенса:
`saturated = tanh(input * saturationDrive)`
Подмешивание сатурированного сигнала управляется `saturationMix`. Для сохранения общей громкости применяется автоматическая компенсация: сигнал делится на `tanh(saturationDrive)`.

Г. Bitcrusher (Биткрашер и Даунсэмплинг)
Реализует цифровую деградацию в два этапа:
1.  Sample & Hold (Даунсэмплинг): Сигнал прореживается во времени. Шаг дискретизации увеличивается в `1.0 / sampleRateRatio` раз. Значение сэмпла удерживается на протяжении этого интервала.
2.  Квантование амплитуды (Bit Reduction): Диапазон сигнала делится на `2^bitDepth - 1` дискретных уровней. Входящий сэмпл округляется до ближайшего разрешенного уровня:
    `crushed = round(input * levels) / levels`
    Поддерживается снижение битности вплоть до экстремальных 4 бит.

Д. Vinyl Crackle (Эмуляция щелчков винила)
Случайный генератор с заданной вероятностью (`crackleLevel * 0.00008f`) генерирует мгновенные импульсы. Эти импульсы пропускаются через полосовой фильтр первого порядка (IIR), превращая резкие цифровые пики в мягкие органические щелчки пыли.

Е. Horror Reverb
Параметры ревербератора `juce::Reverb` динамически привязаны к макро-ручке Vibe. Чем сильнее эффект Vibe, тем больше комната (`roomSize` до 0.92) и уровень влажного сигнала (`wetLevel` до 0.45), создавая глубокий психоделический эффект пространства.

4. SCALE LOCK И CHORD ASSISTANT
--------------------------------
Реализовано в `SynthVoice` при обработке входящих MIDI-нот.
*   Scale Lock (Привязка к ладу): Массив ступеней лада (`scaleSteps`) используется для фильтрации полутонов. Если сыгранная нота не входит в выбранный лад (Major, Minor, Pentatonic, Dorian, Phrygian, Lydian, Mixolydian), она автоматически сдвигается вниз до ближайшей разрешенной ступени тональности (`keySelect`).
*   Chord Assistant: На основе выбранной тональности строит аккорды:
    *   Triad: Основной тон + терция + квинта.
    *   7th Chord: Добавляет септиму.
    *   Retro Arpeggio: Вместо одновременного звучания нот аккорда запускается быстрый перебор ступеней (арпеджио) с частотой, имитирующей звуковые чипы NES/GameBoy, которые не поддерживали аппаратную полифонию.

5. RETRO ROM EXPORTER (РЕТРО-ЭКСПОРТ КОДА)
------------------------------------------
Реализован в `RetroRomExporter.h` и `RomExportWindow.cpp`. Преобразует параметры звука или сыгранные ноты в код для реальных игровых консолей:
1.  PICO-8 SFX: Генерирует массив Lua-таблиц, задающих высоту тона, громкость, эффект и форму волны для каждого из 32 шагов звукового редактора PICO-8.
2.  NES 2A03 (6502 ASM): Генерирует код на ассемблере 6502 для инициализации звукового чипа NES APU, записи в порты `$4000`/`$4002` параметров громкости, скважности импульса и частоты.
3.  SEGA Genesis (YM2612 VGM): Генерирует ассемблерные инструкции для FM-синтезатора YM2612 (запись регистров операторов FM-канала: фидбек, алгоритм связи, частота, мультипликаторы и ADSR-параметры).
4.  GameBoy Color (GBDK C): Генерирует исходный код на C для компилятора GBDK, управляющий регистрами звука GameBoy (`NR10`, `NR11`, `NR12`, `NR13`, `NR14`) для генерации звука на первом (импульсном) канале.

6. ДИЗАЙН И ИНТЕРФЕЙС (UI/UX)
-----------------------------
Интерфейс выполнен в едином неоновом стиле (Dark Neon Synthwave) с использованием шрифта Outfit (загружается из бинарных ресурсов).
*   Кастомный LookAndFeel (`CustomLookAndFeel`) переопределяет отрисовку слайдеров: вместо стандартных шкал рисуется неоновый градиентный круг с эффектом свечения и центральным указателем.
*   Кассетная анимация: Во вкладке FX на основе таймера с частотой 30 Гц отрисовываются две вращающиеся бобины кассеты. Скорость вращения динамически модулируется Wow & Flutter параметрами из аудиопотока для визуализации детонации.
*   Интегрирован буферный осциллограф (`OscilloscopeComponent`), отображающий проходящую аудиоволну в реальном времени.
